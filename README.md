# Spendly

### 🇪🇸 Español

Spendly es una aplicación web full-stack de gestión de gastos personales diseñada para ayudar a los usuarios a registrar, organizar y visualizar sus finanzas de forma simple y clara.
Permite crear categorías, registrar gastos y consultar un dashboard con métricas y gráficos que facilitan el análisis del comportamiento financiero.
El sistema incluye autenticación de usuarios y separación de datos por cuenta.

### 🇺🇸 English

Spendly is a full-stack personal expense management web application designed to help users track, organize, and visualize their finances in a simple and intuitive way.
Users can create categories, log expenses, and access a dashboard with metrics and charts to better understand their spending behavior.
The system includes user authentication and per-user data isolation.

## ⚙️ Tech Highlights

- Full-stack app (Frontend + Backend API)
- Authentication with JWT
- REST API architecture
- CRUD system for expenses and categories
- Data visualization dashboard
- Multi-user data isolation
- Dockerized development environment

## How to run

```bash
./run.sh
```
Stop:

